# Instrucciones para Imágenes del Blog

## Avatar del Sidebar
- **Archivo**: `avatar.png`
- **Tamaño**: 200x200 píxeles (cuadrado)
- **Formato**: PNG con fondo transparente preferible
- **Descripción**: Tu foto de perfil o logo personal

## Favicon
- **Archivo**: `favicon.ico`
- **Ubicación**: `assets/img/favicons/`
- **Tamaño**: 32x32 píxeles (estándar)
- **Formato**: ICO (recomendado) o PNG

### Crear Favicon Completo (Opcional)
Puedes agregar múltiples tamaños para mejor compatibilidad:
- `favicon-16x16.png`
- `favicon-32x32.png`
- `apple-touch-icon.png` (180x180)
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `site.webmanifest`

## Imagen de Preview Social
- **Archivo**: `social-preview.png`
- **Tamaño**: 1200x630 píxeles
- **Descripción**: Imagen que aparece cuando compartes el blog en redes sociales

## Dónde Conseguir Imágenes
- **Avatar**: Usa tu foto profesional o crea un avatar con herramientas como:
  - Canva
  - DALL-E / Midjourney
  - GitHub Avatar Generator
  
- **Favicon**: Herramientas para crear favicons:
  - https://favicon.io/
  - https://www.favicon-generator.org/
  - Canva (export como ICO)

## Ejemplo de Uso
Una vez que agregues las imágenes, se mostrarán automáticamente:
- Avatar en el sidebar izquierdo
- Favicon en la pestaña del navegador
- Preview en redes sociales al compartir enlaces
