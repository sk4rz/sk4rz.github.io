
# Configuración del Entorno

Tener las herramientas adecuadas es crucial. Esto es lo que uso:

-   **SO:** Se recomienda una distribución de Linux (como Arch o Debian).
-   **Depurador:** GDB con una extensión como Pwndbg o GEF.
-   **Desensamblador:** IDA Pro o Ghidra.
-   **Editor:** VS Code o Neovim con los plugins apropiados.
